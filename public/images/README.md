# Images Required

Please make sure the following images exist in this directory:

- `hero1.webp` - First hero image
- `hero2.webp` - Second hero image
- `wines.webp` - Wine menu image
- `cocktail.webp` - Drinks menu image
- `food.webp` - Food menu image

Recommended image dimensions:
- Hero images: 1920×1080 px (16:9 ratio)
- Menu card images: 600×400 px

If you're missing any of these images, you can place placeholder images with these filenames or update the components to use your actual image filenames.
